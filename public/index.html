Справка

Что важно знать

Откуда цены?

Snapshot собирается GitHub Actions из UEX и публичного crowdsource SC Trade Tools. Если один источник падает, последний рабочий snapshot сохраняется.

Почему прибыль может отличаться?

Star Citizen меняет supply/demand. Маршрут ограничивается трюмом, бюджетом, supply продавца и demand покупателя; неизвестные значения явно отмечаются.

Stanton / Pyro / Nyx

Межсистемные маршруты показывают цепочку систем и jump points из UEX. Временные/изменённые связи подхватятся при обновлении данных.

История цен

В «Разборе рейса» можно запросить реальную UEX commodities_prices_history. Если API недоступен, график не подменяется фейковыми данными.
