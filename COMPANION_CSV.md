# CSV Companion / свои замеры

CSV-импорт в интерфейсе остаётся локальным:

1. Открой опубликованный GitHub Pages сайт.
2. Выбери CSV-файл в поле `CSV Companion / свои замеры`.
3. Браузер прочитает файл локально и рассчитает маршруты рядом с данными SC Trade Tools.

Файл не отправляется в GitHub Pages, SC Trade Tools или куда-либо ещё.

Поддерживаемые названия колонок: `location`, `shop`, `terminal`, `commodity`, `item`, `transaction`, `action`, `price`, `quantity`, `timestamp`, `boxSizesInScu` и похожие варианты.
